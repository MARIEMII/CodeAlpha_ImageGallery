# CodeAlpha_ImageGallery

A responsive image gallery built with HTML, CSS and JavaScript as part of the CodeAlpha Frontend Development internship (Task 1).

## Features

- Responsive grid layout that adapts to phones, tablets and desktops
- Lightbox viewer with next/previous buttons
- Keyboard support (left/right arrows to navigate, Esc to close) and swipe on touch screens
- Hover effects and smooth transitions
- Category filters (bonus)
- Light and dark mode support

## Project Structure

```
CodeAlpha_ImageGallery/
├── index.html
├── style.css
├── script.js
└── images/
```

## How to Run

1. Clone or download this repository.
2. Open `index.html` in any browser.

## Adding Your Own Photos

1. Put your images in the `images` folder.
2. Edit the `photos` list at the top of `script.js`, setting each photo's `file`, `title` and `cat` (category).
